# Upstream comparison

Compared against https://github.com/phuanh004/direct-streams-providers at commit `74160f25db3af739c0acee1ad56495843181c798`. The repository has no declared license; no upstream source files were vendored. It describes Movy, 7Movies and FlyStream adapters for other players. Its README reports playback on an Android TV; that is the upstream author's report, not proof on Botkeep or Troy.

The Movy implementation confirms the supplied mvm1 protocol, double-encoded title, per-title seed, required media headers and thirteen original-audio servers. It also identifies all Movy source rows as HLS, even when their URLs lack `.m3u8`; the previous Troy code incorrectly treated opaque non-Auto URLs as direct files. Troy now marks them HLS, parses numeric and 4K quality labels, and can fetch English subtitles embedded in a Movy response through its session-bound, public-address-validated backend. Fetches are size bounded, redirects forbidden, and SRT-style timestamps converted to VTT. Not all subtitle formats are supported. Fixture and simulated-DOM tests cover selection; actual CDN and browser playback remain unverified.

Upstream uses an 8-second budget and parallel server windows, while the user's supplied guidance warns against concurrent seed activity. Troy keeps its serialized seed/source walk, bounds a lookup to 12 seconds and individual requests to 3.5 seconds, and honors seed TTL (refreshing early). The walk may therefore time out before reaching later servers. A queued lookup waits behind earlier lookups, so the budget begins once its turn starts. In contrast, upstream can collect multiple servers concurrently; Troy stops on its first successful server. Its previous fixed 25-second seed reuse could exceed an upstream seed's actual TTL.

Upstream also implements an external subtitle search, Reno master-height probing, and 7Movies/VidLink and FlyStream adapters. These are not integrated here. FlyStream requires a challenge-browser companion according to upstream, and none is appropriate to install or run blindly on the user's constrained panel. Dubbed Movy servers are also not implemented upstream or in Troy. Live availability, external subtitle service, legal rights, upstream rate limits, and actual playback remain deployment-dependent; no claims of successful Botkeep testing are made.
